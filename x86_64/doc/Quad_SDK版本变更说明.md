# Quad SDK 版本变更说明

### [0.1.2] - 2026-04-30

- 新增定位状态订阅能力，便于业务侧持续监听定位结果。
- `quad_cli` 增加定位状态监听入口，方便定位链路联调与排障。
- 放宽导航生命周期状态匹配条件，降低状态抖动导致流程误判的概率。

### [0.1.1] - 2026-04-28

- 定点导航示例与发布包示例统一为 `pose_nav_workflow` / `quad_example_point_nav_workflow`。
- CLI 定位状态输出增加 `yaw_degree`，便于定位姿态排查。
- README、发布包使用指南与 Linux 打包脚本同步更新，示例入口与术语保持一致。

### [0.1.0] - 2026-04-19

- 发布 `robot::sdk::quad` 对外动态库、公共头文件与标准 CMake Config 包。
- 提供 `quad_cli`、导航示例工程以及基础接入文档。
